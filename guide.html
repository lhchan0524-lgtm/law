파일누가 · 언제하는 일

해설.json은 사이트에 올리지 마세요. 사이트 파일은 누구나 주소로 열어 볼 수 있습니다. 해설.json은 선생님 노트북에만 두고, 활동 당일 콘솔에서 [해설 불러오기]로 읽어 들입니다. 그러면 선생님이 공개 칸을 누른 항목만 학생 쪽으로 나갑니다.

2파이어베이스 (실시간 연결)

학생 휴대폰·교사 노트북·TV가 서로 이어지려면 파이어베이스 Realtime Database가 필요합니다. 모의투자 사이트에서 쓰던 프로젝트를 그대로 써도 됩니다. 방 이름(roomId)이 달라서 기록이 섞이지 않습니다.

  1. console.firebase.google.com → 프로젝트 선택(또는 새로 만들기).
  2. 왼쪽 [빌드] → [Realtime Database] → [데이터베이스 만들기] (위치는 아무 곳, 잠금 모드로 시작).
  3. [규칙] 탭에 아래를 붙여 넣고 [게시]. 모의투자 규칙이 이미 있다면 rooms 아래가 열려 있는지만 확인하세요.
{
  "rules": {
    "rooms": {
      "$room": { ".read": true, ".write": true }
    }
  }
}
  1. [프로젝트 설정] → [내 앱] → 웹 앱의 firebaseConfig에서 apiKey · authDomain · databaseURL · projectId를 config.js의 firebase에 넣습니다. (지금 config.js에는 모의투자와 같은 프로젝트 값이 들어 있습니다.)
  2. roomId는 학교·학년이 들어간, 남이 짐작하기 어려운 이름으로 두세요. 해마다 바꾸면 지난 기록과 섞이지 않습니다.
firebase 값을 비워 두면 연습 모드로 돌아갑니다. 한 브라우저 안의 창끼리만 이어지므로, 노트북 하나로 콘솔·공지 화면·학생 화면을 띄워 리허설할 때 쓰세요.

3사이트 올리기

GitHub Pages (모의투자와 같은 방법)

  1. GitHub에서 새 저장소(예: law)를 만들고 [Add file] → [Upload files]로 이 폴더의 파일을 모두 올립니다. 해설.json 제외.
  2. [Settings] → [Pages] → Branch를 main / (root)로 → [Save]. 1~2분 뒤 https://아이디.github.io/law/가 열립니다.
  3. 기존 invest 저장소 안에 law/ 폴더로 올려도 됩니다. 그러면 주소는 …/invest/law/입니다.

Netlify (끌어다 놓기)

  1. app.netlify.com/drop에 폴더를 끌어다 놓으면 주소가 바로 생깁니다.
교사 콘솔(index.html)에는 학생 이름과 학번이 보입니다. 콘솔 주소는 학생에게 알려 주지 말고, 학생에게는 signup.html · student.html · reflect.html의 QR만 나눠 주세요.

4활동 전 준비

  1. config.js에 일시·장소를 적습니다. 조↔사연 연결(caseOfGroup)은 기본값이 1조=사연1 … 4조=사연4입니다.
  2. 콘솔 [참가 신청] 탭에서 참가 신청 QR을 그림으로 저장해 포스터·단톡방에 올립니다. 종이로 받은 조는 [직접 추가]로 넣습니다.
  3. 신청 순서대로 1조~4조가 정해지고, 5번째 조부터는 대기입니다. 활동 전에 명단을 확정하세요(앞 조를 지우면 뒤 조의 조 번호가 바뀝니다).
  4. 종이 자료를 인쇄합니다: 5_조별배부_상담신청서와_증거.pdf(조별 1부), 의견서 종이 백업용 6_개인활동지(휴대폰이 없는 학생용).
  5. 리허설: 노트북에서 콘솔과 공지 화면, 휴대폰 한 대로 student.html을 열어 단계 넘기기·제출·해설 공개를 한 번 해 보고, [설정] → [진행 초기화]로 지웁니다(신청 명단은 남습니다).

5활동 당일 (50분)

단계시간선생님학생 휴대폰
시작 전—콘솔에서 해설.json 불러오기 · [공지 화면 열기] → TV로. QR이 자동으로 뜸QR → 조·이름·학번으로 들어오기
1. 의뢰 접수3분[다음 단계] · 스페이스로 타이머 시작. 조별 봉투 배부사연 탭 열림
2. 개인 검토25분돌아다니며 관찰 — 콘솔 [제출·관찰]에서 칸을 눌러 태그·메모국가법령정보센터에서 조문 찾기 → 의견서 제출
3. 합동 상담 회의12분제출 현황 확인 (TV 오른쪽 아래)조원 의견서 읽기 → 보고서(조장) · 회의 기록과 고마운 점(모두)
4~7. 조별 발표각 2분발표가 끝나면 [해설 공개]에서 그 조 칸을 눌러 공개 → TV·휴대폰에 바로 뜸해설 탭에서 내 판단과 비교
8. 마무리2분공지 QR이 성찰 과제로 바뀜reflect.html — 다음 시간까지
시간이 모자라면 [모두 다시 열기]를 켜서 마감된 의견서·보고서를 다시 받을 수 있습니다. 학생이 쓰던 글은 휴대폰에 저장되어 있어 새로고침해도 남습니다.

6학생 기록 (창체 특기사항 초안)

  1. [학생 기록] 탭에 활동 일시를 적으면 학생마다 자율·자치활동(500자)과 진로활동(700자) 초안이 생깁니다.
  2. 초안의 무게는 교사 관찰 → 의견서·역할·회의 기록 → 성찰(보조) 순입니다. 관찰 없음 배지가 붙은 학생은 초안이 비슷해지므로 관찰 태그나 메모를 꼭 넣어 주세요(비슷함 배지).
  3. 글자 수·바이트(NEIS 기준: 한글 3, 줄바꿈 2)를 함께 보여 주고, '대회·순위·수상' 같은 쓰면 안 되는 말이 있으면 빨갛게 알려 줍니다.
  4. [인쇄용 열기]는 반별로 나눠 담임 선생님께 드리기 좋게 출력합니다. [원본 내려받기]는 근거 자료 전체를 .md로 저장합니다.
  5. 관찰과 초안은 선생님 브라우저에만 저장됩니다. 다른 컴퓨터로 옮기려면 [설정] → [지금 기록 파일로 저장]을 쓰세요.
  6. 담임 선생님께 드린 뒤에는 [모두 지우기]로 학생 개인정보(신청 명단·성찰·관찰)를 지워 주세요.
초안은 출발점입니다. 실제로 관찰하지 않은 내용은 지우고, 학생을 아는 만큼 고쳐서 기재하세요.

7문제 해결

증상확인할 것
콘솔 위에 '연결 실패'config.js의 databaseURL, 파이어베이스 규칙의 rooms 열림, 학교 와이파이가 firebaseio.com을 막는지(휴대폰 핫스팟으로 확인)
학생이 자기 조를 못 찾음신청 명단에 있는지, 정원(4개 조) 밖 대기인지
학번이 맞지 않다고 나옴신청할 때 적은 학번(다섯 자리)과 같은지 — 콘솔 [참가 신청]에서 확인
해설 공개 칸이 안 보임주황 줄의 [해설 불러오기]로 해설.json을 다시 고르기
TV 글씨가 작거나 잘림브라우저 전체 화면(F11), 확대 100%
한 학생이 다른 사람으로 들어감학생 화면 맨 아래 [다른 사람으로 들어가기]
노트북을 바꿈새 노트북에서 해설.json만 다시 불러오면 됩니다. 관찰·초안은 기록 파일로 옮기세요
